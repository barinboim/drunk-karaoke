# Песни, которые едут вместе с сайтом

Сюда кладут **только то, что разрешено распространять**: записи под свободной лицензией
(CC BY, CC BY-SA, CC0), общественное достояние или собственные записи. Коммерческие
фонограммы и тексты песен сюда класть нельзя — сайт публичный.

Одна песня — одна папка:

```
dist/songs/Исполнитель - Название/
  песня.txt      UltraStar с послоговым таймингом
  минусовка.mp3  аудио (минусовка лучше версии с вокалом)
  обложка.jpg    необязательно
```

Потом:

```sh
npm run library     # проиндексирует и dist/songs, и локальные папки
```

Песни внутри `dist/` получают относительные пути и работают одинаково на локальном
сервере и на GitHub Pages. Локальные папки снаружи `dist/` в публикацию не попадают.

Если в индексе не осталось абсолютных путей, `dist/data/library.json` можно коммитить:
тогда у сайта появится свой список песен вместо экрана «принеси свою песню».

## Где брать

- Викисклад и Архив общественного достояния — записи в PD.
- Jamendo, Free Music Archive — треки под Creative Commons (проверяй, что лицензия
  допускает распространение и производные).
- Собственные записи и каверы, права на которые у тебя есть.

Разметку UltraStar под такой трек делают в UltraStar Creator или вручную: формат простой,
см. `dist/ultrastar.js` — какие отклонения парсер прощает.
