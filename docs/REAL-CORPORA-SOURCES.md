# Источники реальных корпусов

Оставшиеся новые файлы собраны офлайн из открытых выгрузок. Строки не сочинялись: HTML очищен, числа преобразуются семантически по-русски (например, `23 ноября` → `двадцать третьего ноября`), латиница транслитерируется, а фразы с неизвестным игре ударением отбираются только после проверки общего словаря.

Целевой объём крупных корпусов — 20 000 пригодных строк, когда такой объём даёт реальный исходник после фильтрации. Строки остаются цельными, числа записываются словами, латиница транслитерируется, ударения проверяются. `wb.txt` — отзывы покупателей Wildberries; `ali.txt` — названия товаров из маркетплейсов.

### Форум Woman.ru

Выгрузка содержит 1 308 238 тредов с URL исходных обсуждений, датами, авторскими постами и ответами; автор набора указывает CC0 1.0. В корпусе игры используются только тексты постов и ответов, не URL и не имена пользователей. Выборка сохраняет каждое сообщение целиком: удаляются контакты, неприемлемые темы, грубая брань, неподдерживаемые ударения и незавершённые конструкции; числа записываются словами, латиница транслитерируется. Отбор стратифицирован по числу слогов с основным весом на диапазон 8–16. Текущая сборка: 20 628 игровых строк после проверки каталога, медиана 12 слогов, 81% записей в диапазоне 8–16.

### Форумы Ruforum

Отдельная агрегированная выгрузка содержит около 58,1 млн сообщений, но площадки в карточке и строках не указаны, поэтому она не атрибутируется Woman.ru. Обработаны доступные shard’ы `00–08` и `10` (52 832 352 строки, 7 апреля 2007 — 9 апреля 2025); `dataset_09` недоступен (404). Выборка сохраняет сообщения целиком и проходит те же фильтры, что Woman.ru. Текущая сборка: 20 619 игровых строк после проверки каталога, медиана 12 слогов, 81% записей в диапазоне 8–16. Скрипт сборки: `node scripts/build-ruforum-corpus.mjs`.

Корпус комментариев YouTube строится отдельно: `npm run corpora-local`. Снимок `.corpus-source/youtube-shorts-comments.txt` получен из `merged_cleaned_comments.txt` репозитория Hugging Face. Англоязычные строки и комментарии, где латиницы больше, чем кириллицы, исключаются; латинские фрагменты в преимущественно русских комментариях транслитерируются. Числительные записываются словами, неизвестные словарю слова не проходят отбор. Текущая игровая выборка — 20 489 строк, медиана 10 слогов, 80% строк в диапазоне 8–16.

Отзывы kino.kz ([набор из 100 502 отзывов](https://huggingface.co/datasets/yeshpanovrustem/100k_movie_reviews_from_kz), CC BY 4.0) пробовали как отдельный игровой корпус, но результат пользователя не устроил. Корпус удалён из игры, а локальный файл выгрузки удалён; повторно скачивать или собирать его не нужно.

Точные размеры последней сборки и количество отобранных строк находятся в `.corpus-source/BUILD-MANIFEST.json` (локальный build-артефакт). Повторная сборка выполняется командой `NODE_OPTIONS=--max-old-space-size=8192 node scripts/build-real-corpora.mjs` после одноразовой установки сборочных библиотек `npm install --no-save parquet-wasm apache-arrow csv-parse`.

## Что выяснилось при сборке

- Все новые файлы используют явный `mode: list`: строки остаются целыми записями, а разделы
  служат только для разнообразия словаря.
- Скрипт `npm run corpora-marketplace` отдельно строит локальный `ali.txt` из
  `.corpus-source/wb-products-expanded.json` — 17 000 карточек прежнего снимка плюс первые
  200 000 строк архива `wb-products-basket-01.json.zst`. Игровая выборка содержит 15 037
  цельных названий, медиана — 12 слогов, 86% записей имеют 8–16 слогов. Названия
  проверяются по словарю ударений; неподтверждённые строки отбрасываются. Латинские фрагменты транслитерированы, числа
  произносимо записаны словами, ударения добавлены и проверены. Поле `nm_colors_names`
  игнорируется; цветосодержащие заголовки ограничены небольшой выборкой, чтобы расширить
  среднюю слоговую длину без преобладания названий оттенков.
- Старый `.corpus-source/ali-base.txt` не имеет подтверждаемой выгрузки-источника и не включается.
  Файл сохранён на диске, но в сборке не используется.
- `wb.txt` содержит только отзывы; `ali.txt` — только целые названия карточек Wildberries.
- `gazeta.txt` содержит 25 025 целых заголовков из поля `title` во всех трёх split набора
  (74 126 исходных строк); числа записываются словами, латиница транслитерируется, слова с
  неподтверждённым ударением отбрасываются. Локальная пересборка: `npm run corpora-gazeta`.
  Это не корпус отзывов AliExpress и не снимок его автопереводов.
- `mail-questions.txt` содержит 50 491 игровую запись из цельных формулировок поля `title`
  набора Yandex Q Full; медиана — 13 слогов. Для коротких фраз оставлены только
  законченные вопросительные заголовки с подтверждёнными словами.
  В игре он отображается под заданным пользователем названием «Вопросы Mail.ru»; источник
  не является Mail.ru Ответами. Лицензия в карточке не указана. Исходный файл
  `.corpus-source/yandex_q.jsonl.zst`; пересборка `npm run corpora-mail-questions`.
- Текущие объёмы целевых корпусов в `dist/corpora/index.json`:

- Цель на 20 000 достигнута для восьми из одиннадцати запрошенных корпусов. Рекламные цитаты ограничены размером пригодной части датасета ФАС; отзывы о лекарствах — локальным снимком RuDReC; этикетки — числом русских составов в Open Food Facts. Не дополнять эти наборы сочинёнными или синтетическими строками.
- Для инструкций к лекарствам найден [zxc0zxc0zxc/rupharm-9k](https://huggingface.co/datasets/zxc0zxc0zxc/rupharm-9k): 9 303 карточки, CC BY 4.0, поля с названием и показаниями к применению. Это не полные листки-вкладыши. Поле показаний можно оценить как отдельный реальный источник фраз, но разбивать его следует только по исходным границам предложений/перечней и после проверки, что корпус не подменяет полные инструкции этим подмножеством. Официальная открытая карточка [ГРЛС Минздрава](https://minzdrav.gov.ru/opendata/7707778246-grls) опубликована в 2017 году и не даёт удобной актуальной выгрузки полных инструкций.
- RuPharm-9k обработан офлайн: выгрузка содержит 9 303 названия препаратов и показания к применению под лицензией CC BY 4.0. После очистки, проверки словарём ударений и удаления дублей в `pills.txt` попала игровая выборка из 3 001 строки. Это больше прежних 518 строк, но не 20 000 и не полные инструкции. Повторная сборка: `CORPORA_ONLY=pills node scripts/build-real-corpora.mjs`.
- Этикетки собраны из полной parquet-выгрузки Open Food Facts на Hugging Face (7.9 ГБ). Её не нужно качать целиком: `duckdb` читает по сети только колонки `code`, `product_name`, `ingredients_text`, `categories_tags` и оставляет карточки с русским текстом; результат — `.corpus-source/openfoodfacts-ru-full.json` (9 МБ, ~28 минут). Запрос — в комментарии блока `label` в `scripts/build-real-corpora.mjs`. Состав режется только по запятым вне скобок: у каждой позиции остаются свои скобки («наполнитель Черника (сахар, вода)»). Позиции с дробями («1,0%») и латиницей («B3», бренды) отбрасываются целиком: честно произнести их нельзя. Разделы — по `categories_tags`, а не по хешу.
- Stack Overflow собран из `ru_stackoverflow.jsonl.zst` (670 МБ) набора IlyaGusev/ru_stackoverflow — это обработанный официальный дамп сайта. Берутся только заголовок и текст вопроса. Блоки `<pre>` и `<code>`, а также любая латиница (почти всегда идентификатор или URL) выбивают клаузу целиком, а не транслитерируются: иначе получается «нулл, нулл» и «лине двести семьдесят четыре». Скобки должны быть парными. Разделы — по тегам. После сборки дамп можно удалить: без него скрипт пропускает Stack Overflow с предупреждением, а не откатывает корпус к 3 тысячам строк старого снимка API.
- `pills.txt` упирался не в источник, а в словарь ударений: из 16 281 уникальной фразы RuPharm-9k словарь пропускал 4 311. Мешали термины и формы, которых нет в OpenRussian: «монотерапии», «генеза», «сопровождающиеся», даже «факторов». Ударения 7 300 таким словам поставила модель [Silero Stress](https://github.com/snakers4/silero-stress) по всем фразам, где слово встречается; они лежат в `accents.txt` отдельным помеченным разделом. Выборочная проверка — 1–2 промаха на 90 слов; системный промах «-иче́ск-» исправлен. Фразы с латиницей (названия бактерий, римские цифры) отбрасываются целиком: транслит давал «стапхйлококкус» и «иии». Итог: 8 910 записей вместо 3 001, но медиана 18 слогов и 30% в ядре — медицинские фразы длинные. Прогон: `pip install silero-stress` в `.corpus-source/venv` (ставит torch), 16 тысяч фраз — полминуты.
- Тот же приём прогнан по «Отзывам на лекарства» (+1 181 слово, 5 672 → 7 058 записей) и «Текстам рекламы» (+1 736 слов, 7 507 → 9 823). Порядок для любого корпуса: `DUMP_UNKNOWN=/tmp/u.json` при сборке выгружает фразы, отсеянные только словарём (фразы с латиницей не выгружаются), затем `.corpus-source/venv/bin/python scripts/stress-unknown.py /tmp/u.json --section … --source … --dry-run` показывает выборку, после проверки — тот же вызов без `--dry-run` дописывает раздел в `accents.txt`, и корпус пересобирается. Скрипт пропускает аббревиатуры и числа, склеенные с единицами («десятьмг»), и исправляет замеченные системные промахи модели (`FIXES`, `WORDS`).
- `fas-advertising.txt` собирается локально командой `npm run corpora-fas-local` из снимка
  `.corpus-source/fas-ad-practice-dataset.csv`. Берутся только дословные цитаты объявлений из
  `ad_content_cited`, а не аннотации `ad_description`; их законченные предложения и фразы
  разделяются по сильной исходной пунктуации. Телефоны, URL, время, многоточия и слова без
  подтверждённых ударений отбрасываются. Числа пишутся словами, латиница транслитерируется.
  Локальная выборка содержит 7 507 строк с приоритетом 8–16 слогов. При
  некоммерческой публикации сохранить атрибуцию Екатерине Якуненко, ссылку на источник и
  CC BY-NC-SA 4.0; указать изменения, а производный файл корпуса распространять под той же
  или совместимой лицензией. Код игры лицензируется отдельно.
- Общий словарь ударений остаётся единственным источником нормы: `npm run accents` после
  сборки сообщает ноль локальных ударений в новых корпусах.

Проверка результата:

```sh
npm run corpora
npm test
npm run accents
```

## Товары и переводы

Отдельный поиск по открытым каталогам, Hugging Face, GitHub и публикациям не выявил
лицензированной выгрузки именно русских неудачных автопереводов AliExpress.
AliExpress-110K содержит около 39 500 уникальных англоязычных карточек AliExpress в виде
110 484 троек «заголовок, атрибут, значение», но для исходной выгрузки не удалось подтвердить
лицензию; её разрешено использовать только в локальном прототипе до выяснения прав.

Кандидат-переводчик — [Helsinki-NLP/opus-mt_tiny_eng-rus](https://huggingface.co/Helsinki-NLP/opus-mt_tiny_eng-rus):
25,4 млн параметров, Apache 2.0, distilled-модель на корпусе Tatoeba. Это всё ещё модель общего
перевода, а не копия закрытой системы Alibaba. Тестовые строки показаны и согласованы
пользователем по уровню кривизны. Результат такой обработки следует обозначать как
«переводы модели из реальных заголовков», а не как дословный корпус AliExpress.

Пользователь одобрил характер генерации tiny-модели: смешные смысловые промахи вроде
«спиртный болван» оставляем, но строки с непереведённой латиницей исключаем целиком.
Экспериментальный локальный прототип `dist/corpora/aliexpress-translated.txt` был получен из 42 614
англоязычных заголовков набора [AE-110K](https://github.com/lanmanok/ACL19_Scaling_Up_Open_Tagging/blob/master/publish_data.txt).
Для каждого заголовка проверены greedy- и sampled-переводы одной tiny-модели. После отсева
латиницы, постановки ударений [Silero Stress](https://github.com/snakers4/silero-stress)
и удаления нечитаемых слов осталось 1 152 цельные строки; медиана — 13 слогов.
Затем добавлено 929 строк длиной 17–24 слога, чтобы покрыть длинные музыкальные строки;
итого 2 081 запись, медиана — 16 слогов, доля ядра 8–16 — 55%.
Неизвестных слов без ударения нет. Коротких записей для строк песни в 1–7 слогов в этой выборке не нашлось,
так что проверка корпуса предупреждает о неполном покрытии таких длин. В исходных данных AE-110K лицензия не подтверждена,
поэтому прототип предназначен только для локального тестирования и не должен попадать в
