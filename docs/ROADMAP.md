# Планы

## Английские песни — сделано

Работает: разметка читается, слоги и ударения берутся из CMUdict, деление написания под слоги
сверено на контрольных словах, протяжные ноты сопоставляются по классу гласной. Русский корпус
на английскую песню ложится штатно.

Что осталось по теме:

- Английского датасета пока нет — поём русские под английские мелодии.
- Слова вне CMUdict (имена собственные, новые слова) получают нейтральное ударение. Можно
  завести `accents-en.txt` по образцу русского.
- Второй вариант произношения из CMUdict отбрасывается, берётся основной.

## Оценка пения — сделано

Интонация, ритм, золотые ноты и охват; итог по шкале до десяти тысяч с разрядами от
«А микрофон включён?» до «Золотой голос». Что можно добавить дальше: живой индикатор попадания
прямо во время пения (сейчас оценка только после), история результатов, разбор по строкам
с показом, где именно уехал тон.
