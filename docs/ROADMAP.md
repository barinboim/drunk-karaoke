# Планы

## Английские песни

Разметка UltraStar на английском разбирается тем же парсером — упирается не в неё, а в фонетику.
Сейчас `dist/ultrastar.js` сознательно отказывает латинице понятным сообщением. В коллекции из
169 папок англоязычных ровно 2 (`Green Day`, `The Beatles`), в файлах — 9.

Что нужно сделать:

1. **Словарь ударений.** CMUdict (общественное достояние, ~134 тысячи слов): каждая гласная
   фонема помечена `0`, `1` или `2` — безударная, главное ударение, побочное. Ложится на нашу
   модель почти дословно: `analyzeWord` уже возвращает вектор ударений по слогам.
2. **Токенизатор.** Сейчас `/[а-яё́]+/`. Нужен второй режим `/[a-z']+/` с выбором по языку
   песни (`#LANGUAGE` в разметке или автоопределение по доле латиницы).
3. **Счёт слогов.** В русском это число гласных букв. В английском — число гласных **фонем**
   из CMUdict, написание не поможет: `through` — один слог, `every` — два, а не три.
4. **Протяжные ноты.** Сейчас сравниваем гласную букву. Для английского сравнивать надо гласную
   фонему (`AA`, `IY`, `UW`…), иначе вся логика мелизмов не работает.
5. **Слова вне словаря.** CMUdict не знает имён собственных и новых слов. Нужен запасной путь —
   либо набор правил, либо наш `accents.txt` на английский лад.
6. **Датасеты на английском.** Существующие русские не подойдут: нужен хотя бы один свой.

Оценка: основная работа — пункты 1–3, остальное по мелочи. Модель движка менять не придётся,
она уже оперирует абстрактным «вектором ударений по слогам».
