# Создание минусовок из плюсовых фонограмм

Эта инструкция описывает восстановление минусовки для песни UltraStar, когда в папке есть только версия с вокалом.

## Что используется

Для отделения вокала применяется Demucs с моделью `htdemucs` и режимом `--two-stems=vocals`. Результат состоит из двух файлов:

- `vocals.wav` — выделенный вокал;
- `no_vocals.wav` — минусовка, которую нужно использовать в караоке.

Окружение Demucs находится рядом с пакетом дубляжа:

```text
/Users/barinboim/Work/Coding/!Games/dub-choice/dc_dubpacks/.venv/
```

В нём лежат Python, `torch` и Demucs. Файл Whisper-модели из `studio/server/paths.py`:

```text
/Users/barinboim/Work/Coding/!Games/dub-choice/dc_dubpacks/models/ggml-large-v3-turbo.bin
```

для отделения вокала не нужен: это модель распознавания речи, а не Demucs. Студия запускает Demucs через тот же `.venv`.

## Вариант через студию

Из каталога `app` проекта `dub-choice` запусти:

```bash
cd /Users/barinboim/Work/Coding/!Games/dub-choice/app
node studio/dev.mjs
```

Открой `http://localhost:5174` и импортируй исходную фонограмму. После обработки стемы находятся внутри проекта в каталоге:

```text
projects/<id>/work/sep/htdemucs/<имя-исходника>/
```

Нужный файл — `no_vocals.wav`. Студия использует устройство `mps` на Mac; если оно недоступно, запускай Demucs с `cpu`.

## Вариант из терминала

Для исходного MP3:

```bash
VENV=/Users/barinboim/Work/Coding/!Games/dub-choice/dc_dubpacks/.venv/bin/python
INPUT="/путь/к/плюсу.mp3"
OUT="/tmp/demucs-minus"

"$VENV" -m demucs \
  --two-stems=vocals \
  -n htdemucs \
  -d mps \
  -o "$OUT" \
  "$INPUT"
```

Для CPU замени `-d mps` на `-d cpu`. Если трек очень длинный и не помещается в память, добавь сегментацию, например:

```bash
"$VENV" -m demucs --two-stems=vocals -n htdemucs -d mps \
  --segment 7 -o "$OUT" "$INPUT"
```

После завершения ищи:

```text
$OUT/htdemucs/<имя-исходника>/no_vocals.wav
```

## Конвертация в MP3

Для библиотеки UltraStar удобнее хранить минусовку в MP3. Конвертируй WAV с постоянными параметрами:

```bash
ffmpeg -y -i no_vocals.wav \
  -codec:a libmp3lame -q:a 2 -ar 44100 -ac 2 \
  "Исполнитель - Название (instrumental).mp3"
```

Не заменяй исходный плюс до проверки результата. Сначала положи минусовку рядом с ним и прослушай начало, куплет, припев и финал.

## Как положить минусовку в папку песни

Минимальная структура:

```text
Исполнитель - Название/
  Исполнитель - Название.txt
  Исполнитель - Название.mp3
  Исполнитель - Название (instrumental).mp3
  обложка.jpg
```

Имена с `instrumental`, `минус` или `minus` распознаются индексатором как минусовки. При наличии нескольких разметок лучше явно указать файл в заголовке `.txt`:

```text
#MP3: Исполнитель - Название.mp3
#INSTRUMENTAL: Исполнитель - Название (instrumental).mp3
```

Если заголовок `#INSTRUMENTAL` не поддерживается конкретной разметкой, достаточно имени файла с `instrumental` — `scripts/library.mjs` выберет его автоматически.

После добавления файла пересобери локальный индекс:

```bash
cd /Users/barinboim/Work/Coding/!Games/robot-karaoke
npm run library -- "/Users/barinboim/Work/Coding/!Games/UltraStar mini songs"
```

В выводе должно появиться увеличение числа песен «с минусовкой».

## Проверка результата

Проверить, что файл читается и имеет нормальную длительность:

```bash
ffprobe -v error \
  -show_entries format=duration:stream=codec_name,sample_rate,channels \
  -of default=noprint_wrappers=1 \
  "Исполнитель - Название (instrumental).mp3"
```

Проверить, что MP3 начинается с допустимого заголовка:

```bash
xxd -l 16 "Исполнитель - Название (instrumental).mp3"
```

Нормальный файл обычно начинается с `ID3` или MPEG sync-байтов. Если `ffprobe` не видит длительность, браузер и сайт тоже, скорее всего, не смогут открыть дорожку.

## Что проверять на слух

- Перед разделением проверь синхронизацию `.txt` с исходным MP3. Совпадение длительности последней ноты с концом трека само по себе не доказывает правильный тайминг: в песне может быть длинное вступление или инструментальный хвост.
- В UltraStar время ноты рассчитывается как `GAP / 1000 + beat × 60 / (BPM × 4)` секунд. Сравни начало первого вокала с первой нотой и проверь ещё несколько вокальных входов дальше по песне.
- Для оценки точного начала можно получить стем вокала через Demucs и найти первый отчётливый вокальный звук; транскрипция Whisper помогает локализовать фразы, но её временные метки могут быть грубыми. Прослушай как минимум начало, середину и поздний участок.
- Если все ноты сдвинуты примерно на одинаковое время, исправь только `#GAP`: новый GAP в миллисекундах равен старому GAP плюс `1000 × (фактическое время вокала − текущее время ноты)`. Если расхождение постепенно растёт, проверь `#BPM` и темповые изменения; одного GAP тогда недостаточно.
- После изменения GAP заново проверь несколько фраз в игре. Не сдвигай заметно всю разметку на основании только длительности трека или одной неточной автоматической метки.
- Пример: у Michael Jackson — Billie Jean первый вокал начинался примерно в 29,25 с, а первая нота по старому `#GAP:33728` — в 33,728 с. GAP исправлен на `29250`; совпадение последней ноты с концом MP3 до этой проверки было ложным признаком точной синхронизации.
- вокал должен быть значительно тише, а не просто отфильтрован эквалайзером;
- ударные, бас и стереопанорама не должны пропадать вместе с голосом;
- в местах с бэками, реверберацией и хором остатки вокала допустимы;
- начало, вокальные входы и конец должны совпадать с плюсовым треком;
- уровень не должен клипповать после конвертации;
- если в исходнике уже была тишина или повреждённый контейнер, сначала нормализуй его через `ffmpeg`, а потом запускай Demucs.

## Частые ошибки

### Demucs не найден

Проверь путь к Python из `.venv`:

```bash
test -x /Users/barinboim/Work/Coding/!Games/dub-choice/dc_dubpacks/.venv/bin/python && echo OK
```

### Нет `no_vocals.wav`

Посмотри последние строки вывода Demucs и проверь, что запуск завершился без ошибки. Также проверь, что каталог `-o` доступен для записи.

### Минусовка не появилась на сайте

Убедись, что:

1. файл лежит в той же папке, что `.txt`;
2. имя содержит `instrumental`, `minus` или `минус`, либо путь прописан в `#INSTRUMENTAL`;
3. файл не повреждён;
4. папка добавлена в ветку `songs` репозитория;
5. после загрузки завершилась Pages-сборка.

### В минусовке слышен вокал

Это ограничение разделения, а не ошибка UltraStar. Попробуй модель `htdemucs`, не используй `vocals.wav` вместо `no_vocals.wav` и сравни несколько участков песни. Для сложного хора или сильной реверберации остатки голоса могут сохраниться.
