# Песни на сайте

Песни **не хранятся в основной ветке**. Они живут в отдельной ветке `songs`, и владелец
проекта грузит их туда вручную через веб-интерфейс GitHub. Локальная разработка этой папки
не видит и никогда её не трогает: `dist/songs/` в `.gitignore`, коммиты её не переписывают
и не удаляют.

При сборке сайта GitHub Actions подмешивает ветку `songs` в `dist/songs/`, пересобирает
список песен и публикует. Ничего вручную делать не нужно.

## Как добавить песню

1. Открой ветку `songs` в репозитории на GitHub.
2. Загрузи папку песни: `Add file → Upload files`, перетащи папку целиком.

```
Исполнитель - Название/
  песня.txt      UltraStar с послоговым таймингом
  минусовка.mp3  аудио (минусовка лучше версии с вокалом)
  обложка.jpg    необязательно
```

3. Коммить прямо в ветку `songs`. Сайт пересоберётся сам, песня появится в списке.

Чтобы убрать песню — удали её папку в ветке `songs`. Тоже прямо на GitHub.

## Что можно класть

**Только то, что разрешено распространять:** записи под свободной лицензией (CC BY, CC BY-SA,
CC0), общественное достояние или собственные записи. Сайт публичный — коммерческие фонограммы
и тексты песен сюда класть нельзя.

Где брать: Викисклад и Архив интернета (общественное достояние), Jamendo и Free Music Archive
(Creative Commons — проверяй, что лицензия разрешает распространение), собственные записи.

Разметку UltraStar под трек делают в UltraStar Creator или вручную. Формат простой, а какие
отклонения наш парсер прощает — написано в `CLAUDE.md`.

## Локальная библиотека

Она отдельная и в публикацию не идёт: `npm run library` индексирует папки с песнями на твоём
компьютере, и `dist/data/library.json` в git не попадает. Одно другому не мешает.
