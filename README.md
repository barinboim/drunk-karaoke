# Пьяное караоке · Drunk Karaoke

Мелодия и ритм настоящей песни остаются нетронутыми, а слова заменяются **целыми записями** из совершенно постороннего датасета — по умолчанию из названий товаров маркетплейса в машинном переводе. Человек поёт «Ролл „Филадельфия“ с лососем» там, где был припев. Шутка держится не на случайности, а на дисциплине: записи берутся **целиком, подряд и без перемешивания**, как будто робот честно зачитывает меню сверху вниз.

Всё работает локально: ни LLM, ни нейросетей, ни API-ключей, ни единого запроса наружу. Новые строки каждый раз собирает JavaScript у тебя в браузере.

## Запуск

Нужен только Node.js, зависимостей npm нет.

```sh
npm run library     # проиндексировать папки с песнями (один раз и после пополнения)
npm run backdrops   # скачать базу фонов с Викисклада (один раз, ~5 МБ)
npm start           # http://127.0.0.1:4173/
```

Пробел — пуск/пауза, Esc — назад к списку песен. «К реплике» переносит к началу следующей музыкальной фразы (нажимай подряд, чтобы идти дальше), «Пересобрать» даёт новую версию текста, «Плюс» включает ту же запись с вокалом (чтобы услышать, как строка поётся), «Весь текст» показывает все строки и расчёты — там же у каждой строки есть «♪», чтобы послушать одну музыкальную фразу с голосом.

## Три режима пения

| режим | что делает |
|---|---|
| **Просто петь** | как караоке-автомат: музыка, текст, ничего не пишется |
| **По фразам** | запись по одной музыкальной фразе. Музыка подводит к строке, на экране идёт отсчёт, запись сама останавливается в конце строки. Дублей сколько угодно: послушать, переписать, удалить, идти дальше |
| **Всю песню** | один заход от начала до конца, без остановок |

После записи кнопка «★ Оценка» разбирает спетое: интонацию (попадание в ноту, октава не важна),
ритм, золотые ноты и охват. Итог — до десяти тысяч, с разрядом от «А микрофон включён?» до
«Золотого голоса», и с процентом по каждой записанной реплике прямо в списке дублей.

«Сохранить» открывает окно экспорта: **ролик** с картинкой и текстом (9:16 для Reels и Shorts, 1:1 или 16:9) либо **только звук** в WAV. Отрезок — вся песня или только записанное. Ролик снимается в реальном времени: минусовка и дубли сводятся офлайн, кадр рисуется на canvas и пишется в MP4 (или WebM, если браузер не умеет MP4) вместе со звуком. Считается офлайн, в браузере; микрофон, дубли и сведение никуда не уходят. У записи есть кольцевой запас в 0.6 с до строки и 0.8 с после — ранний вдох и позднее «а-а-а» не обрезаются, а каждый дубль нормализуется, чтобы шёпот и крик легли в один микс.

## Экран

Эстетика дешёвого караоке-диска: Comic Sans, чёрная обводка, зелёная заливка едет по букве ровно по времени ноты. Иерархия строк — поём (белым с заливкой), следом (тусклее и желтее), как было в песне (серым, мельче всех).

Фон: первым кадром обложка самой песни, дальше — павлины, водопады и Пизанская башня из `dist/media/backdrops`, подмешанные обложками чужих песен. Картинки намеренно ушаканы (мелкий кадр + низкое качество JPEG), чтобы выглядеть как пережатое видео с диска. `npm run backdrops` собирает их с Викисклада — ключей не нужно, всё свободно лицензировано, авторы и лицензии складываются в `CREDITS.json` рядом.

## Откуда берутся песни

`npm run library` обходит папки с караоке-разметкой UltraStar и складывает `dist/data/library.json`. По умолчанию просматриваются:

- `../UltraStar mini songs` — общая коллекция рядом с проектом;
- `жуки батарейка` и `Альянс - На Заре` — папки внутри проекта.

Другие пути передаются аргументами: `npm run library -- /путь/к/песням`. Файлы **не копируются и не изменяются**: сервер отдаёт их с места по адресу `/library/<номер папки>/<файл>`. Для каждой папки выбирается лучшая разметка (минусовка важнее дуэта), подходящее аудио (минусовка важнее версии с вокалом), обложка из заголовка `#COVER`, а дубликаты одной песни схлопываются.

На текущей коллекции: **169 песен из 169 папок**, 127 с минусовкой — включая англоязычные.

Английские песни поддерживаются: слоги и ударения берутся из CMUdict, а не из написания.
Собрать словарь: `npm run cmudict` (качает CMUdict, кладёт 3.6 МБ рядом с остальными данными).
Корпус может быть на другом языке, чем песня.

## Что умеет читать разметку

`dist/ultrastar.js` чинит реальные караоке-файлы, а не требует идеальных:

- ноты с несколькими гласными делятся на слоги с пропорциональным таймингом (так устроен примерно 1% нот в коллекции);
- ноты без гласных приклеиваются к соседнему слогу;
- дуэты `P1`/`P2` сводятся в одну дорожку по времени, дубли партий отбрасываются;
- пересекающиеся ноты подрезаются, распев без предыдущего слога и строки без гласных не роняют разбор;
- латинские двойники кириллицы (`a`, `e`, `o`, `p`…) внутри русских слов чинятся;
- поддерживаются абсолютные и относительные (`#RELATIVE:YES`) тайминги, UTF-8 и Windows-1251.

Понятной ошибкой отвечают: смена темпа по ходу песни, отсутствие `#BPM`, англоязычная разметка.

## Алгоритм

1. **Запись — неделимая единица.** Файл-список даёт одну запись на строку и разделы по
   `## Заголовок`. Проза (свой .txt со сплошным текстом) режется по знакам препинания на законченные клаузы.
2. **Строка песни собирается из 1–4 целых записей,** сумма слогов которых **точно** равна числу
   нот. Записи берутся из разных мест корпуса, а не подряд: иначе строка выходит однообразной
   («Пицца … · Пицца …»). Таблица достижимости гарантирует, что выборка не зайдёт в тупик.
3. **Повторяющиеся строки песни получают один и тот же текст** — припев остаётся припевом.
4. **Протяжные ноты.** Нота длиннее 0.9 с — это место, где вокал тянут на одной гласной. Движок
   сравнивает саму гласную (я поётся как [а], ё как [о]) и проверяет, можно ли слог протянуть.
   На «На заре» совпадение гласной выросло с 3% (чистая случайность) до 52%, а доля слогов,
   которые вообще можно тянуть, — с 76% до 93%. Никаких исключений под конкретные песни.
5. **Ударения — судья, а не генератор.** Вектор ударений строки сравнивается с вектором
   комбинации, долгие ноты весят больше. Рифма с одной из четырёх предыдущих строк — бонус.
6. **Оценка комбинации:** `−3.5 × расхождение ударений + 1.6 × совпадение гласной на протяжных
   нотах − 0.9 × непротяжный слог на долгой ноте + 0.55 × рифма − 0.9 × то же последнее слово
   − 0.7 × неизвестные ударения − 1.8 × повторное использование − 0.7 × одинаковое первое слово
   у соседей − 0.3 × соседи из одного раздела + 0.25 × соседство в файле`.
7. Одинаковые данные, словарь, алгоритм и seed дают одинаковый результат. Замеры на «Батарейке»:
   расхождение ударений 0.3%, соседей из одного раздела 0%, 30 разных версий на 30 seed.

## Датасеты

| файл | что это | записей |
|---|---|---|
| `ali.txt` | товары маркетплейса в машинном переводе | 665 |
| `pills.txt` | инструкция к лекарству | 518 |
| `ads.txt` | доска объявлений | 412 |
| `menu.txt` | меню кафе и ресторанов | 522 |

У **каждого** многосложного слова во всех корпусах известно ударение: чего нет в OpenRussian,
лежит в `dist/data/accents.txt`. Проверить датасет:

```sh
npm run check -- dist/data/ads.txt
```

Скрипт покажет режим разбора, число записей и разделов, распределение длин, недостижимые длины
строк и список слов без ударения. Во всех пяти он пуст.

Как делать и пополнять датасеты — **`docs/DATASETS.md`**. Общая памятка по проекту — `CLAUDE.md`.

## Проверка

```sh
npm test
```

Проверяется: записи корпуса совпадают с исходным файлом посимвольно; проза режется только по знакам препинания; каждая строка состоит из целых записей, взятых подряд, и не пересекает раздел; число слогов ровно по нотам; повторяющиеся строки песни получают один текст; ход по корпусу действительно предпочитает продолжение; seed воспроизводим и даёт разные версии; у датасета меню нет слов без ударения; UltraStar (четвертные доли, склейка согласных, деление многогласных нот, дуэты, англоязычный отказ); плейхед на вступлении, паузах, границах и в конце; резервуар на большом корпусе ограничен.

## Файлы

- `dist/engine.js` — записи, индекс пробегов, beam search. Чистые функции без DOM.
- `dist/ultrastar.js` — терпимый разбор караоке-разметки.
- `dist/worker.js` — подбор вне потока интерфейса; при смене только seed индекс переиспользуется.
- `dist/app.js` — экран выбора песни, сцена, плеер, локальный импорт файлов.
- `dist/recorder.js` — захват микрофона через AudioWorklet с кольцевым запасом; `dist/mixer.js` — офлайн-сведение с лимитером, WAV и нарезка отрезка; `dist/studio.js` — три режима, дубли и окно сохранения; `dist/video.js` — рендер караоке-кадра на canvas и съёмка ролика.
- `scripts/library.mjs` — индексация папок с песнями; `scripts/backdrops.mjs` — сбор фонов; `scripts/check-corpus.mjs` — проверка датасета; `scripts/server.mjs` — локальный сервер с поддержкой Range.
- `dist/data/dictionary.json` — словоформы [OpenRussian](https://github.com/Badestrand/russian-dictionary), CC BY-SA 4.0; `scripts/build-dictionary.py` воспроизводит сборку из `.cache/openrussian`.
- `dist/data/accents.txt` — свой словарь-дополнение поверх OpenRussian. В нём чинится любое неверное ударение, и туда же добавлены местоимения и служебные слова: в OpenRussian нет их склонения, поэтому «тобой», «нами», «него» иначе остаются без ударения.

`dist/data/library.json` и папки с песнями исключены из git: в индексе лежат абсолютные пути к твоим локальным файлам. Сайт никуда не опубликован.
